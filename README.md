# مستخرج النصوص العربية من الصور

أداة ويب مجانية تستخرج النصوص العربية من الصور بدقة عالية باستخدام Google Gemini. ارفع صورة واحدة أو عشرات الصور، وستجد تحت كل صورة مربعاً فيه نصها جاهزاً للنسخ، فتعرف بسهولة أي نص يعود لأي صورة.

**رابط الأداة:** https://sam96sd.github.io/arabic-ocr/

## المميزات

- رفع صور متعددة دفعة واحدة، أو سحبها وإفلاتها، أو لصقها بـ <kbd>Ctrl</kbd>+<kbd>V</kbd>.
- كل صورة لها بطاقة مستقلة: رقم الصورة، اسم الملف، حالة المعالجة، ومربع نص قابل للتعديل مع زر نسخ.
- نسخ حرفي للنص مع الحفاظ على الأسطر والفقرات والتشكيل والأرقام والكلمات الإنجليزية.
- تكبير الصورة بالضغط عليها لمقارنة النص بالأصل.
- زر "إعادة الاستخراج" لأي صورة بمفردها، وزر لإعادة كل الصور الفاشلة.
- "نسخ الكل" وتحميل النتائج كملف **TXT** أو **Word**، مع عنوان لكل صورة.
- معالجة الصور بطابور، وإعادة المحاولة تلقائياً عند تجاوز حدود الخطة المجانية.
- واجهة عربية تعمل على الجوال والكمبيوتر، مع وضع ليلي تلقائي.

## طريقة الاستخدام

1. افتح [رابط الأداة](https://sam96sd.github.io/arabic-ocr/).
2. في أول مرة اضغط **الإعدادات** والصق مفتاح Gemini، ثم اضغط **حفظ**. يكفي ذلك مرة واحدة على كل متصفح.
3. أضف الصور بالطريقة التي تناسبك، وسيبدأ الاستخراج تلقائياً.
4. انسخ نص كل صورة من المربع الذي تحتها، أو استخدم **نسخ الكل** أو **تحميل Word / TXT**.

## الحصول على مفتاح Gemini مجاناً

1. ادخل إلى [Google AI Studio](https://aistudio.google.com/apikey) بحساب Google.
2. اضغط **Create API key** (إنشاء مفتاح).
3. انسخ المفتاح، وهو يبدأ عادة بـ `AIza`، ثم الصقه في إعدادات الأداة.

> الخطة المجانية لها حد لعدد الطلبات في الدقيقة واليوم. الأداة تنتظر وتعيد المحاولة تلقائياً عند الوصول للحد في الدقيقة. وإذا انتهت حصة اليوم، يمكنك اختيار نموذج آخر من الإعدادات (مثل Flash-Lite).

## الخصوصية والأمان

- المفتاح يُحفظ في متصفحك فقط (localStorage)، ولا يوجد في هذا المستودع ولا يُرسل إلى أي جهة غير Google.
- الصور تُرسل مباشرة من متصفحك إلى Gemini API لاستخراج النص، ولا تمر على أي خادم آخر.
- لا تشارك مفتاحك مع أحد. إذا استخدمت الأداة على جهاز عام، فاضغط **حذف المفتاح** من الإعدادات بعد الانتهاء.

## التقنية

موقع ثابت (HTML وCSS وJavaScript) يعمل على GitHub Pages دون خادم ودون خطوة بناء. الملفات:

- `index.html`: هيكل الصفحة.
- `style.css`: التصميم.
- `app.js`: الطابور، والاتصال بـ Gemini، والنسخ، والتصدير.
